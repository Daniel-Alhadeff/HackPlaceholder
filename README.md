Interactive and scalable system to build and fly rockets around a 10:1 scale model of our solar system.
- Nested Sphere of influence orbital modal calculated running in SpacetimeDB
- All data lives in SpacetimeDB - theoretically supports extremely high players
- No networking, or SpacetimeDB data edits as ships move. All orbits are modeled as a orbital steady states from an epoch time - extreemly low networking overhead
